# Tutorial harnesses

Harnesses the tutorials install from GitHub, so a reader can try a remote install without making a
repository of their own.

| Harness | Used by | Why it is here |
|---|---|---|
| [librarian](https://github.com/eyelock/ynh/tree/develop/docs/tutorial/harnesses/librarian) | [A First Delegate Session](../first-delegate-session.md) | A delegate from a Git URL that runs one hook, so it needs `ynh trust accept` |

Change one only together with the tutorial that installs it: the tutorial shows its trust digest.
